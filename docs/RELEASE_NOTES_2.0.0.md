# FilmNegar 2.0.0

## Visual redesign
- Wider responsive desktop layout (up to 1440px)
- Cinematic dark palette with restrained blue and amber accents
- New branded homepage hero
- Refined cards, poster rails, spacing, and navigation
- Responsive refinements for mobile and desktop

## Compatibility
- Existing application logic and Supabase-backed data flows are retained.
- No database schema or SQL migration is required for this visual-only release.

A pre-release backup branch is maintained separately in GitHub.
